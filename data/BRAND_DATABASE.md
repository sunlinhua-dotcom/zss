# 周生生品牌文案数据库 (Brand Database)

## 1. 核心品牌调性与产品线结构
周生生的文案整体风格注重**情绪共鸣、美好寓意与场景感**打造。涵盖从活泼可爱的IP联名，到西式浪漫的婚嫁，再到东方醇厚祝愿的传统佳品。

### 1.1 IP 联名系列 (三丽鸥家族)
* **核心基调**：活泼、治愈、萌趣、好运、元气。
* **代表角色及人设**：
  * **帕恰狗**：好奇心满格，活力萌动，造型多变（墨镜酷飒、达摩福气、星星许愿）。*文案高频词*：治愈陪伴、趣搭出圈、玩转搭配。
  * **大眼蛙**：呆萌纯真，热爱冒险。*文案高频词*：福袋满满、专属守护、好运随行。
  * **凯蒂猫 & 大宝**：温柔热心，开朗明媚。*文案高频词*：开挂玩心、加载可爱、缤纷色彩。
* **应用场景**：日常穿搭、小红书种草、年轻化社媒矩阵（小红书/微博频发）。通常强调“单戴叠搭都出彩”。

### 1.2 婚嫁与浪漫系列 (V&A / PROMESSA / 微糖 / 星宇)
* **核心基调**：优雅、深情、恒久、仪式感、高级感。
* **代表系列方向**：
  * **V&A 馆藏系列**：皇室灵感（维多利亚女王与阿尔伯特亲王），复古浪漫。强调“欧式美学”、“手工勾丝”、“典雅”。
  * **PROMESSA**：注重爱意回应与双向奔赴。“小皇冠”、“双V造型”、“同频共振”、“钻光作答”。
  * **微糖系列**：日常生机与幸运。“金钱草/金叶”、“拉丝工艺”、“装点日常”。
* **应用场景**：情人节（如白色情人节）、纪念日。排版通常更精致，充满留白与钻光呼应。

### 1.3 东方瑞兽与传统文化 (生生有礼 / Charme / 黄金摆件)
* **核心基调**：祥瑞、威严、高级质感、祝福绵长、文化底蕴。
* **代表产品与图腾**：
  * **生肖与图腾**：酷黑生肖（结合凯尔特结与酷黑工艺），骏马奔腾（硬金绒毛电铸，矫健身姿）。
  * **东方瑞兽**：招财貔貅/金蟾（财运），护宅麒麟/福寿龙龟/吉祥瑞象（平安、家业昌隆）。
* **应用场景**：节庆（CNY）、送礼（长辈/商务/本命年）。*文案高频词*：福蕴常随、骏程万里、匠心淬炼、绵长祝愿。

* **标题公式**：【系列名称】+ 【主IP/核心元素】+ 【短句修饰（情感/动作）】，例如：《三丽鸥家族 | 帕恰狗活力萌动，玩转搭配》或《V&A新品｜典藏华冠，传世浪漫》。

## 4. 品牌调性指南（提炼自已通过审批的 FA 文案）

### 4.1 句式特征
* **短句排比，诗意节奏**：4-6字短句并列，留白呼吸，节奏感鲜明
* **产品-寓意双线交织**：每一句都紧扣具体设计/工艺/系列名，再赋予美好含义，从不空洞抒情
* **画面感驱动**：文案本身就像一幅画面，读者能"看到"产品的样子
